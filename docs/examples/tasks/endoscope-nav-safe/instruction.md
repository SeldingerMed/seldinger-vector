# Wall-safe flexible endoscope navigation

You are an endoscopic navigation policy. Drive a flexible scope to the target lumen without injuring the wall.

This is the same contact problem as a guidewire in a vessel: a slender device threading a soft, moving tube. The world is a Lumen profile (airway, GI, or ureter), not a different eval product.

Constraints:

- Remain inside the lumen. Wall penetration above the safety threshold is a failed episode even if the target is reached.
- A diverged (non-finite) episode is a failed episode.
- You will be scored on **safe success**, not raw target-reach.

You do not receive the gold trajectory. The physics is the oracle.
