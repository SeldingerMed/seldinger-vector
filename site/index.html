02 / The contract

One path from package to replay.

The kernel knows ports and invariants, not procedure names. Task authors bring the world and verifier. Agent authors bring the executable package.

  1. 01

    Bind

    Refuse incompatible task and agent ports before execution.

    gym-policy ↔ gym-policy
  2. 02

    Run

    Execute immutable packages against a pinned world or held-out split.

    org/name@version
  3. 03

    Verify

    Emit hard gates, soft metrics, and abstention as separate outcomes.

    TrialVector[]
  4. 04

    Replay

    Reconstruct the result from a self-contained, content-addressed bundle.

    --expect-head

03 / Why a vector

A mean can absorb injury. A gate cannot.

Reach, accuracy, and Dice can be useful metrics. None is permission to erase a penetration event, a missing observation, or a refusal to answer.

04 / What ships

The evidence travels with the result.

A run is a directory, not a screenshot. It contains the packages, configuration, trial vectors, deterministic scorecards, projection when requested, and a head derived from the payload.

05 / Boundaries

What this evidence does not say.

Trust starts with a system that names the edge of its claim.

  • 01

    The public Lumen row is a pinned simulation result, not proof of clinical safety or sim-to-real transfer.

  • 02

    The AngioStress row verifies a benchmark release contract, not model improvement, regulatory performance, or patient benefit.

  • 03

    Credentialing named surgeons remains a gated future mode. This release evaluates procedural models and agents.

  • 04

    OR-Audit is alpha software. Package contracts and artifact formats are runnable, but the service layer is not yet hosted.
